⚡ WHO AM I?

yo im q04ti. welcome to my tiny corner of the web. i got tired of every single portfolio looking like the exact same generic template with "Hi, I'm Alex 👋 Let's build something amazing together". where is the personality?

so i built this retro desktop site from scratch. no react, no tailwind, no massive node_modules folder. just clean html, css, and vanilla javascript that runs fast.

🛠️ TOOLS I USE

javascript, typescript, python, canvas, web audio api, linux, and mechanical keyboards.

✨ RANDOM FACTS

  • 88x31 buttons were peak web design and should make a comeback.
  • i like making lightweight stuff that loads in under 100ms.
  • cookie banners and popups on every site drive me crazy.
  • there is a secret code hidden on this page... try the classic konami code on your keyboard.
  • pet mochi the desk cat over in CyberCat.pet.
